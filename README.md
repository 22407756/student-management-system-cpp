# 🎓 Student Management System in C++

## 📌 Overview
This is a console-based Student Management System developed using C++.
It allows users to manage student records using a simple menu-driven system with login security and validation.

---

## ✨ Features
- Secure login system (username & password)
- Add new students
- Remove students
- Search student by ID
- Display all students
- Show top-performing student
- Grade calculation (0–100)
- Input validation (letters only / numbers only)

---

## 🛠️ Technologies Used
- C++
- Structures
- Arrays
- Functions
- Loops
- Input validation

---

## ▶️ How to Run

### Compile:
g++ main.cpp -o app

### Run:
./app   (Windows: app.exe)
